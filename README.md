# MyGameVault

## 🇬🇧 English

MyGameVault is an Android app for gamers to manage their video game collections, track their in-game progress, and follow their friends' activity.

### Key Features:
* **Game Library:** Track games by status (Owned, In-Progress, Finished).
* **Game Ratings & Reviews:** Rate the games you've played and write personal reviews to share your thoughts.
* **Wishlist & Price Tracking:** Save the games you want to play! The app automatically finds the lowest available prices across various digital stores and sends notifications about sales.
* **Social Feed:** Follow other users and see their latest activities (e.g., when they finish a game).
* **Statistics:** Visual charts and detailed statistics about your gaming habits.

### Tech Stack:
* **Frontend:** Java, Android SDK, XML Layouts, Material Design
* **Backend:** Supabase (PostgreSQL database, Auth, Storage)
* **Networking:** Retrofit2 and OkHttp3 (Interceptors for automatic OAuth2 token refreshing)
* **External APIs:** IGDB API (https://api.igdb.com/) and CheapShark API (https://www.cheapshark.com/api)

## 🇭🇺 Magyar

A MyGameVault egy androidos alkalmazás, amellyel a játékosok kezelhetik videojáték-gyűjteményüket, nyomon követhetik a játékon belüli előrehaladásukat, valamint figyelemmel kísérhetik barátaik tevékenységét.

### Fő funkciók:
* **Játékkönyvtár:** Játékok rendszerezése státusz szerint (Megvan, Folyamatban, Kijátszva).
* **Értékelések és Vélemények:** Értékeld a végigjátszott játékokat, és írj róluk saját kritikát.
* **Kívánságlista és Árfigyelő:** Mentsd el a játszani kívánt játékokat! Az alkalmazás automatikusan megkeresi a legalacsonyabb árakat a különböző digitális áruházakban, és értesítést küld az akciókról.
* **Közösségi Hírfolyam (Feed):** Kövess be más felhasználókat és lásd a legújabb aktivitásaikat (pl. ha értékelnek vagy befejeznek egy játékot).
* **Statisztikák:** Vizuális grafikonok és részletes statisztikák a játékos szokásaidról (befejezési arány, átlagos értékelések stb.).

### Technológiai háttér:
* **Frontend:** Java, Android SDK, XML Layouts, Material Design
* **Backend:** Supabase (PostgreSQL adatbázis, hitelesítés, fájltárolás)
* **Hálózatkezelés:** Retrofit2 és OkHttp3 (Interceptorok az automatikus OAuth2 token frissítéshez)
* **Külső API-k:** IGDB API (https://api.igdb.com/) és CheapShark API (https://www.cheapshark.com/api)
